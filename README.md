# Módulo 3 · Actividades interactivas (FUNDER)

Material del **Programa de formación profesional en Gestión de Emprendimientos Verdes y Modelo de Negocios Sostenibles** · FUNDER · Escuela de Formación Empresarial «Mons. Cándido Rada» (Grupo Social FEPP).

## Contenido
| Archivo | Actividad |
|---|---|
| `index.html` | Página de inicio con enlaces a todas las actividades |
| `ruta-verde.html` | **Ruta Verde**: reto de inicio del módulo (6 estaciones) |
| `canasta-verde.html` | **Canasta Verde**: producto verde, bioproducto o convencional |
| `numeros-que-crecen.html` | **Números que Crecen**: inversión, costos de producción y proyección de ventas |
| `presentacion/Modulo3_CANVAS_Emprendimientos_Verdes.pptx` | Presentación del módulo con formatos editables |

## Cómo publicarlo
Settings → Pages → *Deploy from a branch* → rama `main`, carpeta `/ (root)`.
La página quedará en `https://USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/`.

Cada juego es un solo archivo HTML sin dependencias: también puede abrirse directamente en el navegador.
